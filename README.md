# 🤖 Бот-Репетитор по Математике

Telegram-бот с AI-репетитором, который помогает школьникам решать задачи по математике через диалог с наводящими вопросами.

## ✨ Возможности

- 🧑‍🏫 **AI-репетитор** - ведёт ученика к правильному ответу через вопросы
- 📸 **Распознавание фото** - можно сфотографировать задачу из учебника
- 📊 **Отслеживание прогресса** - статистика решённых задач
- 💰 **Управление токенами** - контроль расходов на AI
- 🔐 **Система доступа** - коды активации и управление подписками
- 📦 **Авто-бэкапы** - резервное копирование базы данных

## 🚀 Быстрый запуск

### Способ 1: Через BAT файл (Windows)
```
Дважды кликните на run_bot.bat
```

### Способ 2: Через командную строку
```bash
cd d:\math-tutor
python main.py
```

Бот автоматически:
- Установит недостающие зависимости
- Применит миграции базы данных
- Запустится и будет готов к работе!

## 📋 Требования

- Python 3.10+
- SQLite (оптимизирован с WAL mode для 50+ пользователей)
- Telegram Bot Token
- OpenAI API Key

## ⚙️ Конфигурация

Создайте файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=ваш_telegram_bot_token
ADMIN_IDS=telegram_id_админа
OPENAI_API_KEY=ваш_openai_api_key
OPENAI_MODEL=gpt-4o-mini
ERROR_LOG_CHANNEL_ID=-100xxx (опционально)
BACKUP_CHANNEL_ID=-100xxx (опционально)
```

## ⚡ Производительность

Бот оптимизирован для работы с **50+ одновременными пользователями**:

- **WAL Mode** - одновременное чтение/запись в SQLite
- **In-Memory Cache** - кэширование часто используемых данных (TTL 5 мин)
- **Rate Limiting** - контроль нагрузки на OpenAI API (10 одновременных, 60/мин)
- **Connection Pooling** - переиспользование соединений с БД
- **Async Processing** - полностью асинхронная обработка запросов

Подробности: см. `ОПТИМИЗАЦИЯ_ДЛЯ_50_ПОЛЬЗОВАТЕЛЕЙ.txt`

### Создание миграции
```bash
alembic revision --autogenerate -m "описание_изменений"
```

### Применение миграций
```bash
alembic upgrade head
```
(или автоматически при запуске main.py)

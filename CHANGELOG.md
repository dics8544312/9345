## [2.1.2] - 21.09.2026 (HOTFIX #2)

### 🐛 Исправлено

#### Бэкапы не создавались (MissingGreenlet)
- **Проблема:** Ошибка `greenlet_spawn has not been called` при создании бэкапов
- **Причина:** 
  1. Использование `user.access_codes` вызывало lazy loading
  2. Неправильное использование `telegram_id` вместо `user.id` в запросе кодов доступа
- **Решение:** 
  1. Заменен `user.access_codes` на безопасный запрос через `AccessService.get_user_active_code()`
  2. Исправлен запрос кодов: `activated_by.in_(user_ids)` вместо `activated_by.in_(telegram_ids)`
- **Файл:** `services/backup_service.py`
- **Статус:** ✅ Бэкапы теперь создаются без ошибок

## [2.1.1] - 21.09.2026 (HOTFIX #1)

### 🐛 Исправлено

#### Ошибка при повторных подсказках
- **Проблема:** При нажатии "💡 Дай подсказку" более 1 раза возникала ошибка парсинга Markdown
- **Причина:** AI использовал символы `*`, `_` в тексте, которые ломали парсинг Telegram
- **Решение:** Убран `parse_mode="Markdown"` из всех ответов AI
- **Теперь:** Подсказки можно запрашивать СКОЛЬКО УГОДНО РАЗ без ошибок
- **Файл:** `handlers/student.py`

#### Добавлена обработка ошибок в подсказках
- Try/except блок в функции `get_hint()`
- Понятные сообщения об ошибках для пользователей
- Логирование ошибок в канал

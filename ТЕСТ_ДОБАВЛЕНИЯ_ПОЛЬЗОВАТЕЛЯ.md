# 🧪 ТЕСТ: Добавление пользователя в бота

## 📋 Два сценария

### Сценарий 1: Пользователь УЖЕ запускал бота

**Шаги:**
1. Откройте бота
2. Введите `/admin`
3. Нажмите `👥 Управление пользователями`
4. Нажмите `➕ Добавить пользователя`
5. Введите username существующего пользователя (который уже запускал /start)
6. Введите количество дней (например: 30)

**Ожидаемый результат:**
```
✅ Доступ успешно выдан!

👤 Пользователь: @username
⏰ Период: 30 дней
📅 До: 21.10.2026

💬 Пользователь может сразу начать работу!
```

**Что происходит в БД:**
- Создается запись `AccessCode` с `code = "DIRECT_12345_timestamp"`
- `activated_by = user.id` (ID пользователя в БД)
- `is_active = False` (код активирован)
- `expires_at = сейчас + 30 дней`
- Токены пользователя размораживаются

---

### Сценарий 2: Пользователь НЕ запускал бота (ОТЛОЖЕННЫЙ ДОСТУП)

**Шаги:**
1. Откройте бота
2. Введите `/admin`
3. Нажмите `👥 Управление пользователями`
4. Нажмите `➕ Добавить пользователя`
5. Введите username который НЕ запускал бота (например: testuser123)
6. Введите количество дней (например: 60)

**Ожидаемый результат:**
```
ℹ️ Пользователь @testuser123 не найден

❗ Пользователь еще не запускал бота

💡 Что произойдет:
1. Вы выдадите доступ заранее
2. Доступ будет ждать активации
3. Когда @testuser123 запустит /start - доступ активируется автоматически

➡️ Введите количество дней доступа или нажмите Отмена:
```

После ввода:
```
✅ Отложенный доступ создан!

👤 Username: @testuser123
⏰ Период: 60 дней

💡 Активация:
Когда @testuser123 запустит /start,
доступ активируется автоматически!
```

**Что происходит в БД:**
- Создается запись `AccessCode` с `code = "PENDING_testuser123_timestamp"`
- `activated_by = NULL` (пока нет пользователя)
- `is_active = True` (ждет активации)
- `expires_at = NULL` (будет установлено при активации)
- `duration_days = 60`

**Когда пользователь запустит /start:**
1. Создается `User` с `username = "testuser123"`
2. Находится `AccessCode` с `code LIKE "PENDING_testuser123_%"`
3. Код активируется:
   - `activated_by = user.id`
   - `activated_at = сейчас`
   - `expires_at = сейчас + 60 дней`
   - `is_active = False`
4. Токены пользователя размораживаются
5. Пользователь видит сообщение:
```
🎉 Отлично!

✅ Ваш доступ активирован автоматически!
Администратор уже выдал вам доступ заранее.

Продолжаем регистрацию...
```

## ❓ Возможные проблемы

### Проблема 1: "Пользователь не найден в базе данных"
**Причина:** Функция `give_direct_access()` не может найти пользователя

**Решение:** Убедитесь что пользователь действительно запускал /start

**Проверка:**
```sql
SELECT * FROM users WHERE username = 'testuser';
```

---

### Проблема 2: Отложенный доступ не активируется
**Причина:** Username не совпадает (регистр или опечатка)

**Проверка в БД:**
```sql
-- Проверяем отложенные коды
SELECT * FROM access_codes WHERE is_active = 1 AND activated_by IS NULL;

-- Проверяем код конкретного пользователя
SELECT * FROM access_codes WHERE code LIKE 'PENDING_testuser%';
```

**Решение:** 
- Поиск кода использует `username.lower()` - регистр не важен
- Убедитесь что username точно совпадает
- Username должен быть БЕЗ @

---

### Проблема 3: Ошибка MissingGreenlet
**Причина:** Попытка обратиться к связанным объектам без await

**Решение:** Уже исправлено в версии 2.1+
- Используется `user.telegram_id` сразу после загрузки
- Используется `user.id` вместо ленивой загрузки
- Все запросы через `await session.execute()`

## 🔍 Отладка

### Проверить отложенные коды в БД:

```python
# В Python консоли или скрипте:
import asyncio
from sqlalchemy import select
from database import async_session_maker
from models import AccessCode

async def check_pending():
    async with async_session_maker() as session:
        result = await session.execute(
            select(AccessCode).where(
                AccessCode.is_active == True,
                AccessCode.activated_by.is_(None)
            )
        )
        codes = result.scalars().all()
        
        print(f"Найдено {len(codes)} отложенных кодов:")
        for code in codes:
            print(f"  - {code.code} (дней: {code.duration_days})")

asyncio.run(check_pending())
```

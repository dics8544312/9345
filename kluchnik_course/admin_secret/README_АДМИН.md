# Секретная папка админа

Ученикам не отдавать. Здесь ключи, Привратник и эталонное решение.

| Файл | Что это |
|---|---|
| gate.py | Бот-Привратник: выдаёт слово, проверяет пропуск, даёт одноразовую ссылку в чат выпускников |
| bot_reference.py | Эталонный бот ученика с правильными ключами |
| verify_keys.py | Считает все 7 ключей тем же кодом, что в уроках |
| .env.example | Настройки Привратника |

## Ключи текущего потока

| Урок | Как ученик получает ключ | Ключ |
|---|---|---|
| 1 | Открывает ссылку со `start=c3JjOnZvcm90YS03`, бот декодирует метку | `src:vorota-7` |
| 2 | Печатает `Gate(act='human', user_id=12).pack()` | `jr:human:12` |
| 3 | Видит в консоли состояние анкеты после первого ответа | `Apply:waiting_from` |
| 4 | Запускает key4.py: первое касание, INSERT OR IGNORE | `ads:3` |
| 5 | Запускает key5.py: запрос напоминаний о продлении | `101-104-103` |
| 6 | Запускает mw_test.py: outer и inner middleware | `gate` |
| 7 | Запускает бота дважды и читает ошибку 409 | `conflict` |

Ловушки в ключах: в 4 наивный подсчёт даёт `ads:4`; в 6 тот, кто не понял inner middleware, напишет `garodte`.

## Как запустить Привратника

1. Создай бота у @BotFather — это и есть Привратник. Его username впиши в пост-закреп.
2. Создай чат выпускников. Добавь Привратника админом с правом приглашать пользователей.
3. Отправь в чате выпускников `/chatid` — Привратник ответит ID.
4. Скопируй .env.example в .env, впиши токен и ID.
5. `pip install aiogram python-dotenv` и `python gate.py`. На сервер — как в уроке 7 курса, через systemd.

Проверено на aiogram 3.15 и Python 3.13 на заглушке Telegram API: выдача пропуска, копия вместо пересылки, чужое слово, неверный код, повторное прохождение.

## Новый поток — новые ключи

Если ключи утекли, поменяй входные данные в 2–3 уроках, а остальное оставь:

1. Урок 2: другие значения в `Gate(act='human', user_id=12)`, например `user_id=47`.
2. Урок 4: поменяй список строк в key4.py.
3. Урок 5: поменяй даты в key5.py.
4. Урок 1: закодируй новую метку: `python -c "from aiogram.utils.payload import encode_payload as e; print(e('src:new-label'))"` и замени ссылку.

После правок: те же изменения внеси в verify_keys.py, запусти его, вставь новый список KEYS в gate.py, пересобери PDF командой `python build_pdf.py` и перезапусти Привратника. Выпускники прошлых потоков остаются в базе gate.db.
